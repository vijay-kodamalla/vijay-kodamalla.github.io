Marlin vs FlashInfer: benchmarking NVFP4 W4A16 on Blackwell SM120

CUDA · NVFP4 · FlashInfer · CUPTI · Aug 2026

An open SGLang issue asks whether FlashInfer's bf16×fp4 kernel should replace the incumbent Marlin path on consumer Blackwell. Twenty-one configurations later the answer is mostly no — but the more interesting number is that both kernels leave 36% of the memory bus unused in a regime that should be saturated. Also: two bugs in my own harness, each of which produced a confidently wrong answer first.
